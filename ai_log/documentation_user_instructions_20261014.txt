WRITING STYLE

Use first-person candidate language where appropriate:

Good:
"I designed the harness around..."
"I chose deterministic Decimal arithmetic because..."
"I separated semantic interpretation from deterministic validation..."
"I added regression tests for..."
"I found that..."
"I validated..."
"I kept autonomous actions fail-closed..."
"I used persistent state to..."

Avoid language like:
"Codex designed..."
"Astra implemented..."
"Gemini decided..."
"The AI built..."
"ChatGPT created the solution..."

Technical documentation should describe the SYSTEM and engineering decisions, not which assistant typed each line.

For example:

BAD:
"Codex implemented source-bound calculation provenance."

BETTER:
"I use source-bound calculation provenance so every material numeric input must be traceable to held evidence. AI coding tools assisted during implementation and testing."

BAD:
"Astra discovered duplicate invoice ownership."

BETTER:
"During adversarial testing I found that an original invoice and a resend could be assigned to separate work units. I fixed ownership resolution and added regression coverage."

BAD:
"Gemini fixed the 192 KB issue."

BETTER:
"During semantic testing, I identified an Antigravity CLI input-truncation limit at roughly 192 KB. I added lossless payload compaction while preserving document/page evidence."
